01 / Why ARTIFACTS exists

Measurements exist in depth, but without a common reference their relationships remain ambiguous. A datum arrives; each observation gains a position against it.

Two structures fail to register. A deliberate spatial correction brings their boundaries into agreement. The camera holds the result before entering a different problem.

Relevant evidence is hidden inside a deep observation field. A selected section remains while the surrounding volume withdraws. These distinct capabilities occupy one environment; its central surface becomes the real ARTIFACTS homepage. This is editorial continuity, not a claim of data exchange between applications.

Altus LotViewer

Altus LotViewer.

Reconstruct per-wafer deposition sequences, including interruptions, reruns, partial and excessive deposition counts. The animation illustrates the operation; it is not a live application result. A broken history should still be recoverable.

Altus ANKO Viewer

Altus ANKO Viewer.

Identify the relevant ANKO history and recipe type, then derive the renewal date for each chamber. The animation illustrates the operation; it is not a live application result. Every due date begins with evidence.

Altus WaferCount.

Read the latest configured chamber counters from equipment records. Gauges use configured display maxima. The animation illustrates the operation; it is not a live application result. Every wafer processed should count.

TopoTracer.

Interpolate coordinate measurements into a wafer surface and map. Inspect horizontal and vertical centre profiles or the radial mean. The animation illustrates the operation; it is not a live application result. Variation has a shape.

06 / 16

SPC Pathfinder

SPC Pathfinder.

Filter a chart-link index by mainframe, type and parameter. Select multiple entries and request the matching chart links. The animation illustrates the operation; it is not a live application result. The right evidence should never stay buried.

07 / 16

GaN Met Compiler

GaN Met Compiler.

Bring PL/Plato, LayTec, XRR and XRD measurements into configured calculations, plots and workbook regions. The animation illustrates the operation; it is not a live application result. Different measurements. One engineering record.

08 / 16

GaN Temp Diagnoser

GaN Temp Diagnoser.

Compare process and clean observations with paired diagnostic-master cases. Review possible explanations and recommended checks; a match does not establish a physical cause. The animation illustrates the operation; it is not a live application result. A symptom means little without context.

09 / 16

AIX ΔT Assistant

AIX ΔT Assistant.

Rank heavier plates against colder bare pockets in weight mode, or compare measured thermal offsets in temperature mode. The illustrated pair is BP3 and BP5. The animation illustrates the operation; it is not a live application result. A physical decision needs evidence.

10 / 16

LT Zone Assistant

LT Zone Assistant.

Locate inner and outer angular sampling windows on a five-slot susceptor, with separate anchors and window bounds. The animation illustrates the operation; it is not a live application result. Know exactly where you measured.

11 / 16

GaN XML Assistant

GaN XML Assistant.

Compare named NODE, DEVICE and PROPERTY content, including supported boolean equivalence. Retain changed, added and removed properties with their structural address. The animation illustrates the operation; it is not a live application result. Find the change that matters.

12 / 16

Magus SPC (GaN)

Magus SPC (GaN).

Evaluate configured mean, spread, range and raw checks. The illustrative fixture has mean 102 within 90–110, but one raw value of 112 fails. Release still requires review. The animation illustrates the operation; it is not a live application result. A status should explain itself.

13 / 16

Magus SPC (Legacy)

Magus SPC (Legacy).

Review a configured recent group population while retaining earlier history. The illustrative older excursion is outside the current review window. The animation illustrates the operation; it is not a live application result. The evidence window changes the review.

14 / 16

ANKO Helper

ANKO Helper.

Evaluate the configured checks before deriving the next date from sample date plus cycle. Failed or missing results do not receive a valid renewal date. The animation illustrates the operation; it is not a live application result. A future date has to be earned.

15 / 16

LT Report Compiler

LT Report Compiler.

Parse LayTec analysis with inherited step, zone and wavelength context. Map fields into workbook columns and append beneath existing data. The animation illustrates the operation; it is not a live application result. Context survives the change in format.

Metria SPC

Metria SPC.

Pin an observation, relate parameter traces and inspect a shared interval. Identity matches are distinguished from nearest-time fallback. The animation illustrates the operation; it is not a live application result. The investigation grows. The clue stays.
