01 / Why ARTIFACTS exists

The answer was only
part of the work.

Separate observations find their references. Comparison, sequence and context are reconstructed into one understandable task.

Again.

The completed task clears. Different evidence enters from another direction, but the same relationships have to be reconstructed.

Good reasoning should
outlive the task.

Temporary evidence leaves while its relationships stay. The retained structure accepts new observations, gains repeatable states, and opens into the positions occupied by real ARTIFACTS interfaces.

01 / 16

Altus LotViewer

Altus LotViewer.

Process events are only useful in sequence. Align timestamps, wafer states and durations around the same lot. The animation illustrates the operation; it is not a live application result. A lot is more than its event list. Every event keeps its context.

02 / 16

Altus ANKO Viewer

Altus ANKO Viewer.

Retrieve ANKO schedules across Altus equipment. Read dates in the context of the equipment they belong to. The animation illustrates the operation; it is not a live application result. Individually correct. Difficult to compare. One date. Every equipment lane.

03 / 16

Altus WaferCount

Altus WaferCount.

Collect wafer counts from equipment logs. Review chamber usage as an input to maintenance planning. The animation illustrates the operation; it is not a live application result. Every passage leaves a record. Chamber usage, with its history.

04 / 16

TopoTracer

TopoTracer.

Measurements acquire meaning when their positions are retained. Resolve a contour field from the wafer samples. The animation illustrates the operation; it is not a live application result. The samples are points. Read the region in the whole.

06 / 16

SPC Pathfinder

SPC Pathfinder.

Navigate workcentres and parameter groups to locate the required SPC chart. The animation illustrates the operation; it is not a live application result. The chart is somewhere in here. The search becomes a path.

07 / 16

GaN Met Compiler

GaN Met Compiler.

Gather measurement files, apply predefined calculations and compile the result into a consistent reporting structure. The animation illustrates the operation; it is not a live application result. Separate sources. One reporting task. A report with a traceable beginning.

08 / 16

GaN Temp Diagnoser

GaN Temp Diagnoser.

Bring process and clean-recipe observations into one diagnostic view. Follow the recommended checks before drawing a conclusion. The animation illustrates the operation; it is not a live application result. The observation stays in view. A check. Not a conclusion.

09 / 16

AIX ΔT Assistant

AIX ΔT Assistant.

Use weight and temperature inputs to guide baseplate swaps. Follow each plate from its current position to its new seat. The animation illustrates the operation; it is not a live application result. The inputs have a physical consequence. BP3 and BP5. Exchanged.

10 / 16

LT Zone Assistant

LT Zone Assistant.

Map LayTec inner and outer zones within one coordinate system. Review each boundary in relation to the whole. The animation illustrates the operation; it is not a live application result. Two references. One geometry to establish. Every boundary has a counterpart.

11 / 16

GaN XML Assistant

GaN XML Assistant.

Match properties between reference and target configurations. Read changed settings and constants in context. The animation illustrates the operation; it is not a live application result. A setting belongs to a structure. The difference keeps its parent.

12 / 16

Magus SPC (GaN)

Magus SPC (GaN).

Bring configured GaN SPC charts and parameter states into the same review. The animation illustrates the operation; it is not a live application result. The process is larger than one chart. Attention without losing the picture.

13 / 16

Magus SPC (Legacy)

Magus SPC (Legacy).

Retrieve legacy SPC parameter states and charts within the established review workflow. The animation illustrates the operation; it is not a live application result. The record comes in different forms. Parameter. State. Chart. Together.

14 / 16

ANKO Helper

ANKO Helper.

Align ANKO status and due dates by equipment before deciding what needs attention. The animation illustrates the operation; it is not a live application result. Status needs a place in time. The next action becomes visible.

15 / 16

LT Report Compiler

LT Report Compiler.

Assemble LayTec source information into an engineering report without rebuilding the reporting structure each time. The animation illustrates the operation; it is not a live application result. The analysis exists. The workbook needs it. Append the result to the record.

16 / 16

Metria SPC

Metria SPC.

Inspect equipment parameter traces together. Follow one time window across the signals while retaining each chart. The animation illustrates the operation; it is not a live application result. Five signals. Five separate views. Every trace. The same moment.
