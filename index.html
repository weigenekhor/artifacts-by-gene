01 / How the tools accumulate

01 / Recurring work

Another run.
Familiar work.

Check the variation. Compare the revision. Reconstruct the history. Different days bring back the same kinds of engineering work.

02 / Repeated response

The response shouldn’t
start over.

Each task needs judgment. Rebuilding the same comparison, calculation or report every time adds work without adding understanding.

03 / Retained method

Keep the method.
Use it again.

The useful part is the method: what to align, what to check, what context to preserve. Make that repeatable.

04 / Software

Give the method
an interface.

A dedicated tool puts those steps within reach. The repeated work gains structure; the engineering decision remains yours.

05 / Accumulation

One need at a time.
Sixteen tools later.

History, comparison, diagnosis, planning and reporting. Separate requirements gradually became the collection called ARTIFACTS.

02 / Where the tools are used

Start with the question
in front of you.

A run to reconstruct. A change to verify. A process to investigate.
The task determines the tool.

01

What happened during the run?

Evidence
Process events, wafer states and chamber counts.
Response
Reconstruct the lot history and review equipment usage.
For the engineer
A traceable sequence, with usage in view.

02

What changed between revisions?

Evidence
A reference and a revised recipe or Devices.XML file.
Response
Align corresponding steps or properties. Isolate the differences.
For the engineer
Changes that can be reviewed in context.
Papyrus Reader ↗GaN XML Assistant ↗
03

Where is the variation?

Evidence
Surface measurements and equipment parameter traces.
Response
Locate the region, find the chart, or inspect related signals over the same interval.
For the engineer
Spatial and time context for the next investigation.
TopoTracer ↗SPC Pathfinder ↗Metria SPC ↗
04

What needs checking when temperature drifts?

Evidence
Temperature observations, baseplate inputs and zone geometry.
Response
Work through diagnostic checks and examine the relevant positions and regions.
For the engineer
A structured investigation, with the physical context retained.
GaN Temp Diagnoser ↗AIX ΔT Assistant ↗LT Zone Assistant ↗
05

What is due on the equipment?

Evidence
ANKO schedules, equipment status and due dates.
Response
Review the planned work alongside the current status.
For the engineer
A clearer basis for maintenance planning.

06

What evidence is ready for review?

Evidence
Metrology records, LayTec information and SPC parameter states.
Response
Compile reports or review the relevant release charts in their own tools.
For the engineer
Structured reports and chart context for engineering review.

A note from Gene

Built in the work.
Held to its standard.

I wanted better tools beside me while doing the work. So I started building them.

A comparison that kept coming back. A report that took too much assembly. A process that needed a clearer view. Each tool started with something practical.

There was no suite planned at the beginning. The tools accumulated, one problem at a time. That became ARTIFACTS.

— Gene
